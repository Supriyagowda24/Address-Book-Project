# Address Book Management System 

A C programming project designed to manage contact information efficiently using file handling, structures, functions, and modular programming.

## Project Overview

The Address Book Management System is a menu-driven application that provides an organized way to manage contact details. It allows users to perform essential contact management operations through a simple and user-friendly interface.

## Features

- Add new contacts
- Search for existing contacts
- Edit contact information
- Delete contacts
- Display saved contacts

## Technologies and Concepts

- C Programming
- Structures and Pointers
- Functions and Modular Programming
- File Handling
- Data Management

## Objective

The objective of this project is to apply core C programming concepts to develop a practical application while strengthening programming logic, problem-solving, and code organization skills.
